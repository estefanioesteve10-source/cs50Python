## Final Project: CS50 Bank
For my final project, I developed a **Modular Banking System** with automated PDF generation. Key features include:
* **Architecture:** Modular design using a `src/` package structure.
* **PDF Engine:** Automatic generation of contracts and transaction receipts using `fpdf2`.
* **Testing:** 100% test coverage for core financial logic using `pytest`.
* **Validation:** Robust error handling for overdrafts and invalid inputs.
